# Демонстрационная программа для анализа банковских операций

## Описание
Консольное приложение для анализа банковских транзакций из Excel-файла. Программа предоставляет различные сервисы для работы с финансовыми данными.

## Функциональность

###  Основные модули:

1. **Выгодные категории** (`category_of_cashback`)
   - Анализ транзакций по месяцам
   - Определение категорий с максимальным кэшбэком
   - Ввод: месяц и год для анализа

2. **Инвесткопилка** (`investment_bank`)
   - Расчет суммы для инвестиций
   - Автоматическое откладывание средств
   - Пример: расчет для июня 2025 года

3. **Простой поиск** (`simple_search`)
   - Поиск транзакций по ключевым словам
   - Вывод результатов в JSON-формате
   - Показывает первые 10 найденных записей

4. **Поиск по номеру** (`phone_search`)
   - Анализ транзакций, связанных с телефонными номерами
   - Специфическая обработка мобильных платежей

## Особенности реализации

###  Технические детали:
- **Обработка ошибок:** Программа перехватывает исключения файлов и общие ошибки
- **Очистка экрана:** Автоматическая очистка консоли между операциями
- **Форматирование вывода:** Удобное табличное меню и JSON-форматирование
- **Модульность:** Разделение функционала на независимые сервисы

###  Ключевые функции:
- `clear()` - очистка терминала
- `demonstration_servis()` - главная функция демонстрации
- `reader_exel()` - утилита для чтения Excel-файлов

## Обработка ошибок
Программа обрабатывает:
- Отсутствие файла `operations.xls`
- Некорректный ввод пользователя
- Ошибки чтения Excel-файла
- Общие исключения выполнения

## Разработка
Для расширения функциональности можно:
1. Добавить новые сервисы в папку `src/services/`
2. Реализовать дополнительные утилиты в `src/utils/`
3. Модифицировать главное меню в `demonstration_servis()`

## Примечания
- Программа предназначена для демонстрационных целей
- Требует наличия файла с транзакциями в указанном пути
- Поддерживает русскоязычный интерфейс
